How It Works

A production-quality ML pipeline powering every prediction

🗂️

Real Dataset

Trained on 205 real automobile records with 24 feature dimensions covering engine specs, dimensions, fuel efficiency and more.

⚙️

Smart Preprocessing

Automatic handling of categorical features via one-hot encoding, numerical scaling, and imputation — all inside a scikit-learn Pipeline.

🏆

Best Model Selection

Six regression algorithms are trained and compared. The champion — selected by R² and cross-validation — powers all predictions.

⚡

Instant Predictions

Enter vehicle specifications, click Predict, and receive an estimated price in milliseconds via a REST API — no page reload.

📊

Model Insights

Explore actual vs predicted charts, feature importance rankings, price distributions and full model comparison metrics.

🔒

No Data Leakage

Preprocessing is fitted only on training data. The complete fitted pipeline is serialized so inference is perfectly consistent.
