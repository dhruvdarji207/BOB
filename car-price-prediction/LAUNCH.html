⚡ CarPriceAI
AI-Powered Car Price Prediction — Local Server Launcher

How to Start the App

1
Open a Terminal in this folder
Press Win + R, type cmd and press Enter.
Then navigate to this project folder:
cd "C:\Users\Asus\Desktop\dhruv\Subjects\IBM\BOB\car-price-prediction"
Or simply right-click inside this folder and choose "Open in Terminal" / "Open PowerShell window here".
2
Install dependencies (first time only)
Run this once to install Flask, scikit-learn and other packages:
pip install -r requirements.txt
3
Train the model (first time only)
This creates models/car_price_model.pkl. Already done — skip this if the models/ folder already has files.
python train_model.py
4
Start the Flask server
Run this every time you want to use the app:
python app.py
You should see: * Running on http://127.0.0.1:5000
5
Open the website
Once the server is running, click the button below:
🚀 Open CarPriceAI at http://127.0.0.1:5000

Quick Copy — One After Another

Run these commands in order in your terminal:
pip install -r requirements.txt
python train_model.py
python app.py

Status Checklist

Python 3 installed
Flask, pandas, scikit-learn, joblib installed
models/car_price_model.pkl exists (run train_model.py)
Flask server running (run python app.py)
Browser open at http://127.0.0.1:5000
💡 Why can't I just open this as a webpage?
CarPriceAI uses a Python/Flask backend to run the machine learning model. A plain HTML file has no Python runtime — the ML model lives in car_price_model.pkl and can only run through the Flask server. Once python app.py is running, the full app is available at http://127.0.0.1:5000.
